# Орион-128 — спецификация для эмулятора

## Процессор

- Процессор — i8080.
- Тактовая частота — 2,5 МГц.
- Контроллер дисплея и процессор друг другу не мешают.

### Старт после сброса

i8080 после RESET стартует с адреса 0000, а монитор находится в конце памяти (F800–FFFF).
Решено наложением: после сброса ПЗУ монитора отображается и в нулевые адреса; запись в системный
порт № 1 (F800) наложение снимает.

Начало монитора:

```
F800: C3 42 F8        JMP  F842      ; первый байт ПЗУ — точка холодного старта
...
F842: 31 C9 F3        LXI  SP,F3C9   ; стек в служебном ОЗУ
F845: AF              XRA  A
F846: 32 00 F8        STA  F800      ; снимается наложение ПЗУ на 0000
F849: 32 00 F9        STA  F900      ; страница 0
F84C: 32 00 FA        STA  FA00      ; экран 1
```

Последовательность: PC=0000 → чтение C3 42 F8 из наложенного ПЗУ → переход на F842 →
инициализация стека → обнуление системных портов, после чего нулевые адреса снова становятся ОЗУ.

## Экран

Система координат: начало координат — левый нижний угол, 0,0.

| Угол           | Координаты |
|----------------|------------|
| левый нижний   | 0, 0       |
| правый нижний  | 383, 0     |
| правый верхний | 383, 255   |
| левый верхний  | 0, 255     |

### Раскладка видеопамяти

Видеопамять описывается от левого верхнего угла.

- C000 — первые 8 пикселей по горизонтали (левый верхний угол).
- C001 — 8 пикселей под ними.
- И так далее; 256-я строка — C0FF.
- Дальше следующая вертикальная колонка: C100–C1FF.
- И так до последней колонки: EF00–EFFF.

Внутри байта старший бит (D7) — самый левый пиксель, младший (D0) — самый правый.
Бит, равный 1, — точка; 0 — фон.

Экран, таким образом, разбит на 48 колонок по 8 пикселей: колонка занимает ровно 256 байт
(одна страница адресов), внутри колонки байты идут сверху вниз.

### Адрес пикселя

Раскладка описана от левого верхнего угла, а система координат — от левого нижнего, поэтому
номер строки внутри колонки считается как 255 − Y:

```
адрес = база_экрана + (X / 8) * 256 + (255 − Y)
бит   = 7 − (X mod 8)
```

где X = 0…383, Y = 0…255, база_экрана — из системного порта № 3.

Пример: точка 0,0 (левый нижний угол) — бит D7 байта C0FF; точка 0,255 (левый верхний) —
бит D7 байта C000; точка 383,255 (правый верхний) — бит D0 байта EF00.

## Порты

| Адрес | Назначение                         |
|-------|------------------------------------|
| F400  | порт клавиатуры                    |
| F500  | порт пользователя № 1              |
| F600  | порт пользователя № 2              |
| F700  | порт платы расширения              |
| F800  | системный порт № 1 (только запись) |
| F900  | системный порт № 2 (только запись) |
| FA00  | системный порт № 3 (только запись) |
| FB00  | системный порт № 4 (только запись) |

Все системные порты — только на запись.

### Системный порт № 1 (F800) — управление цветным режимом

| Бит | Значение | Смысл                                                       |
|-----|----------|-------------------------------------------------------------|
| D0  | 0        | палитра № 1 (в монохромном режиме — зелёный на чёрном фоне) |
| D0  | 1        | палитра № 2 (в монохромном режиме — жёлтый на голубом фоне) |
| D1  | 0        | режим 1, 16 цветов                                          |
| D1  | 1        | режим 2, 4 цвета                                            |
| D2  | 0        | монохромный режим                                           |
| D2  | 1        | цветной режим                                               |

### Системный порт № 2 (F900) — управление страницами памяти

| D1 | D0 | Страница              |
|----|----|-----------------------|
| 0  | 0  | основная страница «0» |
| 0  | 1  | страница «1»          |
| 1  | 0  | страница «2»          |
| 1  | 1  | страница «3»          |

### Системный порт № 3 (FA00) — переключение экранов

Область ОЗУ дисплея — это так называемый экран по умолчанию, «1» (не путать со страницей памяти).
Записав в системный порт № 3 значение 0, 1, 2 или 3, можно переключаться между экранами «1», «2», «3», «4».

Адреса экранов:

| Значение порта | Экран | Адреса    |
|----------------|-------|-----------|
| 0              | «1»   | C000–EFFF |
| 1              | «2»   | 8000–AFFF |
| 2              | «3»   | 4000–6FFF |
| 3              | «4»   | 0000–2FFF |

### Системный порт № 4 (FB00) — переключение типов дисплея

Графический или символьный. 0 — графический, по умолчанию.
