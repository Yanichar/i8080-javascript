Orion-128

i8080 at 2.5 MHz, one 64K memory page, 384×256 monochrome display, M1 monitor in ROM.

Keyboard

Click the screen to give it focus, then type. Keys are mapped by physical position, so the host keyboard layout does not matter.

Host keyOrion key
ShiftUS — symbols on the digit keys
CtrlSS — control codes
F9RUS/LAT — toggles the Russian character set

Backspace, DeleteZB

Monitor commands

The monitor prompts with -. Addresses are hexadecimal and arguments are separated by commas.

CommandEffect
D start,endDump memory
M addrExamine and change memory
G addrRun from an address
F start,end,byteFill memory
C start,end,destCompare memory
T start,end,destCopy memory
